# dev-autopilot 要件メモ（話題ごとに分けたもの）

本フォルダは、[要件メモ][memo]（2026-10-11 に凍結していた 1 つのファイル）の凍結を解き、話題ごとのファイルに分けたものである。
分けたのは 2026-10-12 で、分けるときに文は書き換えていない。要件メモは約 900 行あり、古い文と、古い文を改めた「決定」「訂正」が何百行も離れて並んでいたため、人も AI も全体を把握しきれなかった。

## 見直しの進め方

1. 分ける：文を変えずに、話題ごとのファイルに分ける（済み）
2. 古い文を消す：ファイルごとに「古い文」と「古い文を改めた文」の組を一覧にし、メンテナが確認してから古い文を消す。消した文は git の履歴に残る（済み）
3. 矛盾と曖昧なところを解く：ファイルの中と、ファイル同士の食い違いを一覧にし、メンテナと相談して決める。一覧は [09-undecided.md][f09] の「見直しで見つけたこと」と「要件定義書の 10 節から移したこと」にある
4. 仕上げる：本フォルダを要件の正本にする。元の[要件メモ][memo]は、本フォルダを正本にしたときに消す。[要件定義書][req]の扱いも、正本にするときに決める

見直しの間は、元の[要件メモ][memo]を編集しない。見直しの対象は本フォルダのファイルだけにする。

## 分けるときに変えたこと

文の中身は変えていない。変えたのは次の点だけである。

- 各ファイルに題（H1）を足した。要件メモの題「dev-autopilot（自律開発ループ）要件メモ（検討の記録。凍結）」は置いていない
- 4.x の節と、12 節から話題のファイルへ移した節の見出しを 1 段上げた（`###` → `##`）。親の見出し「4. 要件」は置いていない
- 12 節の判断 1〜6 を話題のファイルへ移し、「12 節の判断 N」の見出しを足した。判断 7 と、12 節の冒頭と「反映したもの」は [11-records.md][f11] に置いた
- 移した判断の番号（「6.」など）を残すため、判断の行の直前に markdownlint の MD029 を止めるコメントを足した
- [00-overview.md][f00] の要件定義書へのリンクの定義を、本フォルダからの相対パスに直した

分ける前と後で、空行を除いた行の集合（同じ行の数も含む）が、上の変更を除いて一致することを機械で確かめた。
